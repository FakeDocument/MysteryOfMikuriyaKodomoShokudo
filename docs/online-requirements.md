# 「御厨こども食堂の謎」オンライン版 要件

更新日：2026-10-22

状態：要件整理段階。オンライン版は未実装。

## 目的

プレイヤーがアカウントを登録し、ブラウザから調査ノートとKali Linuxの調査端末を利用できるようにする。プレイヤー自身によるDockerの導入やネットワーク設定を不要にする。

## トップページ・アカウント

| ID | 要件 |
| --- | --- |
| TOP-01 | ユーザーはアカウント登録できる。 |
| TOP-02 | ユーザーはログインできる。 |
| TOP-03 | ユーザーはログアウトできる。 |
| TOP-04 | ログインしたユーザーは自分の調査ノートにアクセスできる。 |
| TOP-05 | ログインしたユーザーは自分の調査用VMを起動できる。 |
| TOP-06 | ユーザーは他のユーザーの調査ノートを閲覧・変更できない。 |

## 調査ノート

| ID | 要件 |
| --- | --- |
| NOTE-01 | 調査ノートの進捗と回答をユーザーごとにサーバー側DBへ保存し、再アクセス時に復元する。 |
| NOTE-02 | 調査メモをユーザーごとにサーバー側DBへ保存し、再アクセス時に復元する。 |
| NOTE-03 | ユーザーは設問への回答を入力・送信できる。 |
| NOTE-04 | サーバー側で回答の正誤を判定し、結果と進捗を調査ノートへ反映する。 |
| NOTE-05 | 正解データはサーバー側で管理し、ブラウザへ正解一覧を配信しない。 |
| NOTE-06 | VMが終了・削除されても、DBに保存したノートの進捗・回答・調査メモは保持する。 |

保存の正本はサーバー側DBに統一する。DB製品と配置は未決定。

## 調査用VM

| ID | 要件 |
| --- | --- |
| VM-01 | ユーザーはブラウザからKali Linuxの調査端末にアクセスできる。 |
| VM-02 | 調査端末から寿司屋サーバーと政府サーバーへアクセスできる。 |
| VM-03 | 調査用VMはインターネットへアクセスできない。必要なツールと攻略対象のデータは事前に用意する。 |
| VM-04 | 初期利用時間は2時間とする。 |
| VM-05 | ユーザーは利用時間を手動で延長できる。 |

VMの終了・時間管理の操作はTryHackMeを参考にする。利用期限を基準とする方式を採用し、延長幅と延長上限は未決定とする。

## 終了・再開の仕様案

以下は、これまでの削除要件とTryHackMeを参考にした操作を具体化する案。詳細は今後確定する。

- 画面に残り時間と延長・手動終了ボタンを表示する。
- 利用期限が切れた場合、またはユーザーが手動終了した場合は、調査環境を削除する。
- ページを閉じても即時終了せず、利用期限までは再接続できる。
- 削除後に再度起動した調査環境は初期状態から始まる。ノートの保存済みデータは引き継ぐ。
- VM内に取得・作成したファイルは調査環境とともに削除されることを、終了前に案内する。

## 実装前に確認する追加候補

| 項目 | 仕様案 |
| --- | --- |
| 認証・認可 | 未ログインでのノート・VM利用を拒否し、画面だけでなくAPIとVM接続時にも利用者を確認する。 |
| VMの所有者 | 他のユーザーのVMに接続したり、延長・終了したりできない。 |
| 環境の隔離 | 他のユーザーの調査環境や、管理用API・DBへ調査端末から接続できない。 |
| 重複起動 | 1ユーザーにつき同時に1環境までとし、起動操作の連打でも環境を重複作成しない。 |
| 状態表示 | 起動中・利用可能・削除中・起動失敗を表示する。 |
| 起動数の上限 | サービス全体の同時起動数に上限を設け、満員時は案内する。 |
| ノートの独立利用 | VMが起動していなくても、ノートの閲覧・回答・メモ編集を利用できる。 |
