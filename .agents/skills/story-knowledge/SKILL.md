# ストーリー知識の運用

1. 物語、登場人物、Flag、証拠、およびプレイヤー向け文章を扱う際は、事前に本ドキュメントの記載内容を確認すること。
2. 各設定間、ならびに実装済みの証拠との間に矛盾が生じていないかを点検すること。
3. 新たに確定した設定は、速やかに本ドキュメントへ反映すること。
4. 回答例や候補名を正史として混同せず、「確定」「仮」「未決定」の各ステータスを厳密に維持すること。
5. 技術方式、TryHackMeへの公開要件、実装進捗は `knowledge` 側に集約し、本ドキュメントへ重複して記録しないこと。
6. 実装済みの調査ノートに表示されるセリフの正本は、`docker/notebook/app/data/chapters/` 配下の章別JSONとする。本ドキュメントにはセリフを転記せず、会話を通じて開示される事実、配置、および演出意図のみを記録すること。

# SushiCTF ストーリー知識

## 確定している基本設定

プレイヤーは、小さな（いささか胡散臭い）探偵事務所で働くアルバイトである。

地域で評判の寿司屋は無料のこども食堂を運営しているが、そこへ通っていた佐々木笑真（12歳・小学6年生）が行方不明となっている。プレイヤーは、食堂で笑真と親しくなった友人・遠藤美咲からの依頼を受け、Webサイトやサーバーから発見した証拠を探偵事務所の調査ノートへ記録しながら、店舗と失踪事件の関連を調べていく。行方不明者は物語の開始当初から一貫して笑真1人であり、捜索対象と真の救出対象が食い違うような構造にはしない。

調査が進むにつれ、以下の真相が明らかになる。

- 寿司屋は、こども食堂を利用して人身御供（生贄）とする子どもを選別しており、笑真もその1人として選ばれ、身柄を確保されていた。
- 日本政府の一部組織が寿司屋に協力している。
- 沖ノ鳥島が海の邪神によって水没するのを防ぎ、日本の排他的経済水域（EEZ）を維持するために、生贄が捧げられている。
- 笑真は近々、政府側へ引き渡される予定となっている。

寿司屋が生贄を選ぶ条件は「肉付きが良い（健康的な体格である）こと」であり、神崎の調査記録を比較すると分かる。また、居なくなっても大きな事件にならないよう、孤立した子供を選んでいる。
数年前に生贄となった宮田奏太の記録、選ばれなかった小林陽向の記録（孤立していないため対象外）、遠藤美咲の記録（肉付きが貧相なため対象外）、そして笑真自身の記録を照らし合わせることで、この条件が見えてくる。みくりや子ども食堂の無料の食事は、単なる善意ではなく、選定した子どもの体格を意図的に整える役割も兼ねている。この事実は直接描写せず、記録の書きぶりから推測させる。

依頼人の遠藤美咲は、笑真が食堂へ通うにつれて目に見えて肉付きが良くなっていたことに、漠然とした違和感を抱いていた。笑真の失踪後、家族は本気で取り合わず、警察も事件性を断定できない中、美咲は自身も同じ食堂の常連であり他人事ではないと薄々察しながらも、大人を通さず単身で探偵事務所へ調査を依頼するに至る。

なお、現実の沖ノ鳥島を題材とするが、作中に登場する政府組織、事件、人物、怪異はすべてフィクションである。

## 物語のトーン

ストーリーラインはシンプルかつ明快に保つ。

序盤は善意のこども食堂にまつわる失踪事件として始まる。中盤で寿司屋が子どもを生贄に選んでいると分かり、終盤で政府と海の邪神が関わる国家規模の秘密へ至る。

長い地の文による説明を避け、名簿、勤務表、メール、業務文書、サーバーログなどの短い証拠を積み重ねて真相を伝える。直接的で残酷な描写は避け、明るい店の日常と非人間的な内部記録の落差で不気味さを生む。

海の邪神は、その姿、声、写真、映像などを直接的に描写しない。これは実装および表現コストを抑える制作上の配慮であり、「正体不明であること」それ自体を重要な主題としているわけではない。したがって、証拠文面（伝承や目撃記録など）の地の文で視覚的特徴に言及すること自体は差し支えないが、プレイヤーに対して画像や映像、詳細な容貌描写を直接提示することは避ける。一方、政府の内部文書においては邪神の実在を前提とし、沖ノ鳥島とEEZの維持に向けて対処すべき現実の脅威として事務的に取り扱う。

海の邪神の名称は「オオクチ様（オオクチサマ）」とする。詳細は「確定している調査の段階」および第4章の証拠文面を参照のこと。名称からは大きな口が想起されるが、具体的な姿形や正体は定義しない。第4章では、オオクチ様「そのもの」を説明する文書と、オオクチ様への「対処」を記した文書を分け、政府側から入手する資料の中で、前者、後者（EEZ維持との関係を含む）、引き渡し予定の順序で開示していく。

オオクチ様は沖ノ鳥島周辺に固有の土地神・信仰対象ではない。海域を移動し、離れた土地の島礁を「島食い」の対象としてきた存在であり、今回の活動では人間側の国家・領有・EEZ上の意味とは無関係に、沖ノ鳥島がたまたま標的となった。資料室の伝承文書には、沖ノ鳥島周辺ではない複数の沿岸地域に残った、単体でも怪談・伝承として成立する三篇を収録する。政府はそれらの記録と現代の観測を比較し、各地で別々に語られてきた出来事を同一の存在・現象として整理している。

## プレイヤー体験

- 主人公にはハッカーとしての特別な設定を付与しない。
- 調査ノートにおける主人公の表示名は「あなた」とする。性別は男性に固定し、主人公の発話では一人称に「僕」を用いる。
- 主人公の確定設定画は `notes/主人公.png` とする。若い日本人男性で、濃紺の無造作な髪、青灰色のパーカー、白いTシャツ、濃灰色のパンツ、濃紺のスニーカー、黒いバックパックを身につける。細身でわずかに猫背の、親しみやすい等身大の青年として描く。
- 序章から第3章にかけては、所長の指示や付箋が初心者向けの誘導と物語上の演出を兼ねる。
- 第4章の冒頭で、所長はオオクチ様の封印準備を進めるために事務所を離れる。ただし、この真の目的は裏設定とし、主人公に対しては行き先も具体的な用件も明かさない。所長が退場した後は終章に至るまで、プレイヤー自身が過去の調査ノートを振り返り、これまでに習得した調査手法を政府側のサイトへ適用していく。
- Flagの提出は、調査ノートの空欄へ人物名や判明した事実を記入していく形式とする。
- 単なるランダム文字列の発見ではなく、証拠を精読・理解した結果を回答させる。
- 最後は調査報告書を完成させ、佐々木笑真の政府への引き渡し予定日時と場所の両方を特定する（引き渡しの阻止が目標）。この2点の組み合わせを最終フラグ（最終回答）とする。

### 調査ノートの会話演出

- 所長と主人公の会話は、キャンパスノート上に人物アイコン付きの吹き出しとして表示する。主人公（表示名「あなた」）を右側に配置し、それ以外を左側に配置する。発言者を色と配置の双方で明確に区別する。地の文は人物名・アイコン・吹き出しを持たない本文として会話の間に表示する。
- 会話は、各章開始時の導入と設問に正解した際に順次展開する。全章共通の調査メモはnoVNC内からも自由に表示・編集できる補助機能とし、保存によって会話や物語進行は発生させない。正解時には判明した事実の整理と言語化、ならびに次の調査方針を提示する。
- 不正解時には新たな会話を発生させず、設問側で証拠との食い違いを通知する。会話が前進すること自体を、正解に達した手応えとして機能させる。
- 既存の証拠開示の順序やミスリードの構造を崩さないようにする。第1章から第3章までの会話ではオオクチ様に一切言及せず、第2章の段階では子どもの選別と政府関係者の存在から児童売買を想起させるに留める。
- 任意ヒントは、「第1章の入口調査」「第3章の検索欄」といった過去の調査ページを再確認させる方向性を基本とする。匿名Samba共有の列挙においては、`-N` オプションの役割とコマンド実行例を段階的に提示する。
- 第4章の最終回答後に解放される終章でのみ、所長をまず電話越しに再登場させる。終章は、完成した調査報告、所長からの電話と主人公の決断、荷捌き所での片柳との対峙、所長の超常的な現場登場と封印、観測結果、翌朝の依頼完了の順に進む。所長は倫理的な答えを先に示したり主人公の代わりに決断したりせず、調査資料から何を読み取ったかを問い返す役割を担う。地の文は、場面、動作、沈黙、時刻の切迫、封印時の超常現象を簡潔に伝え、人物が口にする理由のない説明を肩代わりする。

## 確定している調査の段階

寿司屋サーバー編において、プレイヤーは神崎のSambaアカウントを手がかりに、以下の資料を発見する。

- 子どもたちの友人関係や家庭環境などを調べ上げた調査記録
- 一般顧客に加え、政府関係者を「特別顧客」として記載した顧客台帳
- 従業員の基本プロフィール、メールアドレス、生年月日などを網羅した職員名簿

この段階では、子どもの選定記録と政府関係者の存在から、一連の事件が児童売買であるかのようにミスリードを誘う。オオクチ様の存在は寿司屋側の証拠（第1〜3章）には一切登場させず、政府側の機密文書（第4章）に到達した段階で初めて開示する。

寿司屋サーバー編の最終目標は、神崎の正規アカウントで社内Webメールへログインし、メール検索機能のSQLインジェクションによって御厨の送受信メールを発見することとする。御厨と片柳のやり取りから片柳の業務メールアドレスを見つけ、そのドメイン `kaiiki-hozen.local` を次の調査対象として特定する。ここで調査対象が寿司屋から別サーバーの政府組織へ広がる。

政府サイト編では、片柳のメールアドレスから得られた `kaiiki-hozen.local` を足がかりに調査を進め、政府内部の機密文書へと至る。第4章の内部において、オオクチ様そのものの解説、政府の対処方針、引き渡し計画の順序で真相を開示していく。

具体的な業務は、離島の定点観測、海域保全計画の立案・実施、関係機関および協力者との連携等、多岐にわたる。

片柳のメールアドレスを手がかりに、調査範囲を政府ホストへと拡大する。80番ポートで公開されている観測点一覧と、`/archive/` 配下に残された「定点観測業務引継事項」における「南方第3点」の記載を照合することで、沖ノ鳥島を巡る事案が特異事象「A-07」に該当することが判明する。445番ポートには匿名アクセスが可能な庁内引継用の `handover` 共有が存在し、情報管理係の端末設定票の中に片柳の閲覧端末を移設するためのコードが残存している。8080番ポートのアクセス画面でそのコードを入力すると、片柳の管轄文書が閲覧可能となる。調査ノートでは匿名の共有一覧を調査する方針を設問で示し、`-N` オプションの用法を任意ヒントで解説する。この設定票は、端末の入れ替え時に担当係へ渡して後から回収する予定であった実務資料として演出する。

職員アカウントでは、共通管理簿と片柳の担当文書しか見えない。検索機能のSQLインジェクションで他部署の記録へ到達すると、観測票、伝承、実施要領、保守引継資料をまとめて入手できる。文書内の検索語を繰り返し入力させない。

第4章の調査ノートでは、観測票と伝承から「オオクチ様」および「島食い」の事実を把握させた直後に、実施要領と公開観測点一覧を照合させて「沖ノ鳥島」と「EEZ」を解答させる。その上で、輸送原簿と第3章のメールを照らし合わせ、最終回答となる引き渡しの日時と場所を特定させる。このように、2つの重要な推理に必要な証拠の入手フェーズを明確に区分する。

保守引継資料に記載された過去のジョブ設定を手がかりに、同じ政府サーバー上に存在する別のSamba共有へと侵入する。冒頭で匿名閲覧できた引継資料とは異なり、輸送原簿を格納する `handoff` 共有へ入るには専用のアカウント情報が必要となる。調査ノートでは接続情報の単なる転記に留まらず、共有内の「受入照合簿」に記された受入番号を解答させることで、プレイヤーが原簿へ正しく到達したことを判定する。Web目録は観測記録・方針文書および保守記録の保管、ファイル共有は当日に更新される輸送原簿の管理という、実務に即した役割分担を持たせている。SQLインジェクションで得た設定情報と、第4章冒頭で実施したポートスキャン調査が、ここで一本の線に繋がる。
