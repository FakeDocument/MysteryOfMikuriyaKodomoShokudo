# ストーリー知識の運用

1. 物語、人物、Flag、証拠、プレイヤー向け文章を扱う前に、このファイルの知識を確認する。
2. 設定同士、または実装された証拠との矛盾がないか確認する。
3. 新しく確定した設定をこのファイルに反映する。
4. 回答例や候補名を正史として扱わない。「確定」「仮」「未決定」を維持する。
5. 技術方式、TryHackMe公開要件、実装進捗は `knowledge` に集約し、ここへ複製しない。
6. 実装済みの調査ノートに表示するセリフの正本は`docker/notebook/app/data/chapters/`配下の章別JSONとする。このファイルにはセリフを転載せず、会話で開示する事実、配置、演出意図だけを記録する。

# SushiCTF ストーリー知識

## 確定している基本設定

プレイヤーは小さな（胡散臭い）探偵事務所で働くアルバイトである。

地域で評判の寿司屋は無料のこども食堂を運営しているが、そこへ通っていた佐々木笑真(12歳・小学6年生)が行方不明になっている。プレイヤーは、食堂で笑真と仲良くなった友人、遠藤美咲からの依頼を受け、Webサイトやサーバーから見つけた証拠を探偵事務所の調査ノートへ記録しながら、店と失踪の関係を調べていく。行方不明者は物語開始時点から一貫して笑真1人であり、依頼対象と真の救出対象が食い違うような構成にはしない。

調査によって以下の真相が明らかになる。

- 寿司屋は、こども食堂を利用して人身御供にする子どもを選んでおり、笑真もその1人として選ばれ、確保された。
- 日本政府の一部組織が寿司屋に協力している。
- 沖ノ鳥島を海の邪神による沈没から守り、日本のEEZを維持するため、生贄が捧げられている。
- 笑真は近く、政府側へ引き渡される予定になっている。

寿司屋の生贄選定条件は「孤立していること」と「肉付きが良い(健康的な体格である)こと」の2つを満たす子どもであることが、神崎の調査記録の比較から判明する。数年前にすでに生贄となった宮田奏太の記録(解決済みの過去の事例。笑真とは面識も血縁もない)、選ばれなかった小林陽向の記録(孤立していないため対象外)、遠藤美咲の記録(肉付きが貧相なため対象外)、笑真自身の記録を比較することで、この条件が浮かび上がる。みくりや子ども食堂の無料の食事は、単なる善意ではなく、選定した子どもの体格を意図的に整える役割も兼ねている(この事実は直接描写せず、記録の書きぶりから推測させる)。

依頼人の遠藤美咲は、笑真が食堂に通ううちに目に見えて肉付きが良くなっていたことに漠然とした違和感を持っていた。笑真の失踪後、家庭は取り合わず、警察も事件性を断定できない中、美咲は自分も同じ食堂の常連であり他人事ではないと薄々感じながらも、大人を介さず単身、個人的に探偵事務所へ調査を依頼する。

現実の沖ノ鳥島を題材にするが、政府組織、事件、人物、怪異はすべてフィクションとする。

## 物語のトーン

物語はシンプルに保つ。

序盤は善意のこども食堂にまつわる失踪事件として始まる。中盤で寿司屋が生贄を選んでいることが判明し、終盤で政府と海の邪神が関わる国家規模の秘密へ到達する。

長い説明ではなく、名簿、勤務表、メール、業務文書、サーバーログなどの短い証拠を積み重ねて伝える。直接的で残酷な描写は避け、明るい店の日常と非人間的な内部記録の落差で不気味さを出す。

海の邪神は、姿、声、写真、映像などでは直接描写しない。これは実装・表現コストを避けるための制作上の都合であり、「正体不明であること」自体を物語上重要なテーマとして扱っているわけではない。したがって証拠文面(伝承・目撃談など)の地の文で見た目に触れる記述をすること自体は問題ないが、プレイヤーへ画像・映像・具体的な姿の描写で直接見せることはしない。一方、政府の内部文書では邪神の実在を前提とし、沖ノ鳥島とEEZを維持するために対処すべき実在の対象として事務的に扱う。

海の邪神の名称は「オオクチ様（オオクチサマ）」とする。寿司屋側の証拠にオオクチ様の存在を示す記述は一切含めない。詳細は「確定している調査の段階」と第4章の証拠文面を参照。名称から大きな口を連想させるが、具体的な姿や正体は定義しない。第4章では、オオクチ様「自体」を説明する文書と、オオクチ様への「対処」を説明する文書を分け、政府側から得る資料の中で前者、後者(EEZ維持との関係を含む)、引き渡し予定の順に読ませる。

## プレイヤー体験

- 主人公に特別なハッカー設定は付けない。
- 調査ノート内の主人公の会話名は「あなた」とし、個人名・性別・容姿は設定しない。会話アイコンも顔を描き込まない匿名的なペン画とする。
- 序章〜第3章では、所長の指示や付箋を初心者向けの導線と物語演出に兼用する。
- 第4章の冒頭に、所長はオオクチ様の封印準備を進めるため事務所を出る。ただし、この真の目的は裏設定とし、主人公には行き先も具体的な目的も明かさない。所長の退場後から終章までは、プレイヤーが過去の調査ノートを見返し、これまで学んだ方法を政府側のサイトへ適用する。匿名Samba共有の列挙だけは既習の認証付き操作から飛躍があるため、任意ヒントで`-N`を補足する。
- Flag提出は、調査ノートの空欄へ人物名や判明した事実を書き込む行為として見せる。
- 発見したランダム文字列ではなく、証拠を理解した結果を回答させる。
- 最後は調査報告書を完成させ、行方不明の佐々木笑真の政府への引き渡し予定日時と場所の両方を特定する(引き渡しの阻止が目標)。この2点の組を最終フラグ(最終回答)とする。オオクチ様の封印準備を進めていた所長から電話が入り、プレイヤーが判明した日時と場所を伝え、笑真の救出へ動き出すところで終了する。救出作戦そのものと成否は初版のゲーム内では描かない。

### 調査ノートの会話演出

- 所長と主人公の会話は、キャンパスノート内へ人物アイコン付きの吹き出しとして表示する。所長は左、主人公(表示名「あなた」)は右に置き、発言者を色と配置でも区別する。
- 会話は章開始時の導入に加え、その章で初めて証拠メモを書き込んだ時と、設問へ正解した時に順番に展開する。証拠メモ保存時は「事実を記録したこと」への短い応答、正解時は判明した事実の言語化と次の調査方向を示す。
- 不正解では新しい会話を発生させず、証拠との食い違いを設問内で知らせる。会話の進行を正答の手応えとして使う。
- 序章〜第3章の会話は、既存の証拠順とミスリードを崩さない。第1〜3章の会話ではオオクチ様に触れず、第2章では子どもの選定と政府関係者の存在から人身売買を疑わせる段階に留める。
- 第3章は、片柳の業務メールアドレスから政府側のドメインを特定し、御厨水産の外にも調査先ができたところで終える。
- 第4章冒頭では、主人公が政府側のドメインを調べると決めた後、所長が行き先を明かさず事務所を出る。この退場場面では新しい攻略手順を教えない。
- 任意ヒントは「第1章の入口調査」「第3章の検索欄」など過去のページを見返す方向を基本とする。匿名Samba共有の列挙では`-N`の意味と操作例を段階的に示す。
- 第4章の最終回答後に開く終章でだけ、所長の電話を吹き出しで再登場させる。所長は発見済みの日時と場所を確認し、笑真の救出へ動くことを短く伝える。政府の真相や攻略方法、封印準備について改めて説明させない。

## 確定している調査の段階

寿司屋サーバー編では、プレイヤーは神崎のSambaアカウントを足掛かりに、次の資料を発見する。

- 子どもたちの友人関係、家族関係などを調査した記録
- 一般客に加え、政府関係者を「特別顧客」として含む顧客リスト
- 職員の基本プロフィール、メールアドレス、生年月日などを含む職員名簿

この段階では、子どもの選別と政府関係者の存在から、事件が人身売買であるようにミスリードする。オオクチ様の存在は寿司屋側の証拠(第1〜3章)には一切登場させず、政府側の機密文書(第4章)に到達して初めて明かす。

寿司屋サーバー編の最終目標は、まず神崎の正規アカウントで社内Webメールへログインし、メール検索機能のSQLインジェクションを通じて御厨のメールを発見することとする。そこで御厨と片柳のやりとりを発見し、片柳の業務メールアドレスのドメイン`kaiiki-hozen.local`を次の調査対象として特定する。ここで調査対象が寿司屋から別サーバーの政府組織へ広がる。

政府サイト編では、片柳のメールアドレスから得た`kaiiki-hozen.local`を足掛かりに調査を進め、政府側の機密文書へ到達する。第4章内で、オオクチ様自体の説明、政府の対応方針、引き渡し予定の順に事実を開示する。

保守引継の旧ジョブ設定から、同じ政府サーバーの別のSamba共有へ入る。最初に匿名で読めた引継資料とは異なり、輸送原簿の`handoff`共有には専用アカウントが必要。調査ノートでは接続設定の転記だけでなく、共有内の受入照合簿にある受入番号を答えさせ、原簿への到達を確認する。Web目録は観測・方針と保守記録、ファイル共有は当日修正される輸送原簿という実務上の役割を持つ。SQLで見つけた設定と第4章冒頭のポート調査が、ここでつながる。
