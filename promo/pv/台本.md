# 『御厨こども食堂の謎』宣伝PV 台本

- 尺：42秒／16:9（1920×1080、30fps）。YouTubeとXで同じ動画を使う
- 構成：明るい寿司屋のCMに依頼書が割り込み、CMが壊れたあとは、ふつうのゲーム紹介PVとして進む
- 画：CMは写真のまま1920×1080で描く。CMより後はドット絵（640×360を3倍）で、立ち絵は調査ノートの128×128のものを使う。ただしゲーム紹介は、実画面か、実際の出力・実際に描画したページを使って1920×1080で描く（ゲーム画面をドットで描き直すと実物と違う絵になるため）
- VHSの劣化表現（色のにじみ、走査線、ノイズ、行の横揺れ、下端のヘッド切り替えノイズ、トラッキングの乱れ、録画機の表示）はCMの割り込みから壊れるまでにだけかける。CMの頭はきれいな放送のまま始め、CMより後には劣化をかけない
- 音：コードで合成した効果音と曲。全体にテープのヒスノイズを敷く
- 光過敏に配慮し、全面の明滅は入れない。割り込みは1秒に3回を超えない間隔にする
- ネタバレは第2章の「肉付き: 極上」まで。政府、オオクチ様、沖ノ鳥島、終章、所長の浄衣と片柳の立ち絵は出さない
- 画面の文字は、作中の台詞・証拠・公開サイトの文面だけにする。ナレーションや新しい宣伝文は書かない。例外として、ゲーム紹介とタイトルの場面だけは、機能を短く伝える見出しを入れてよい
- Xは無音で自動再生されるので、音がなくても内容が伝わるようにする

状態の欄：**確定**＝書き出し済みでユーザー確認済み／**試作**＝書き出し済みでユーザー確認待ち／**未制作**＝これから作る

## 5. ゲーム紹介（0:22〜0:33）　試作

ふつうのゲームPVとして、本物のKaliを操作できることと、調べる相手が実際に動くサーバーであることを見せる。ここだけアップテンポな曲に切り替え、1小節（約1.8秒）ごとにカットを切り替える。操作の手順は追わず、1カットに1つの画面を見せる。

| 小節 | 画面 | 見出し |
|---|---|---|
| 1 | Kaliのデスクトップの実画面。端末でNmapを実行した結果 | 「ブラウザから、本物のKali Linuxを操作する」 |
| 2 | 端末でDIRBを打ち込み、結果が流れる | 同上 |
| 3 | 端末でsmbclientから共有に入り、`ls` で一覧する | 同上 |
| 4 | ブラウザで寿司屋HP（`www.mikuriya-suisan.local`）を上からスクロールする | 「調べる相手は、実際に動いているサーバー」 |
| 5 | 社内Webメール（`mail.mikuriya-suisan.local`）のログイン画面に、神崎のメールアドレスとパスワードを入れていく | 同上 |
| 6 | ログイン後の受信箱 | 同上 |

- 1カット目だけは、noVNCで開いたKaliの実画面を使い、本物であることを見せる（`uv run promo/pv/capture_screens.py`）
- 2〜3カット目の端末は1920×1080で描く。文字は、Kaliで実際に実行したコマンドの出力（`uv run python promo/pv/capture_transcripts.py` → `assets/terminal/`）を書き換えずに使う。配色とプロンプトはKaliの実画面に合わせ、書体はKaliの書体に近いMenlo（`㉿` だけApple SD Gothic Neo）。打鍵と出力の流れは1小節に収まるよう、待ち時間だけ詰める
- 4〜6カット目のブラウザは、中身に標的サイトを実際に描画したページを使い、タブとアドレスバーの枠だけを描く。`uv run python promo/pv/capture_pages.py` が、Playwrightのコンテナを一時的に隔離ネットワークへつなぎ、1920幅で描画して `assets/pages/` に保存する（ページは加工しない）
- ドットでは描かない（ゲーム画面をドットで描き直すと実物と違う絵になるため）
- 実画面と端末の出力は、撮影時だけKaliの時計を作中の日時（2026年9月10日 13時台・日本時間）に合わせて撮る（`story_clock.py`）。デスクトップ右上の時計は実時刻のままだが、寄りで画面外になる
- 1920×1080のまま、各カットは1小節かけて一定の速さでゆっくり寄る（速さが途中で変わると30fpsではカクついて見えるため）。カットはつなぎ目を作らず拍の頭で切り、場面の最後だけ黒へ落とす
- 見出しは画面下の半透明の帯に、白いヒラギノ角ゴシックW6で出す。帯は先端に朱の線を付けて左から滑り込ませ、見出しが変わる4小節目でもう一度滑り込ませる
- 曲：短調の打ち込み風の曲（約131BPM、6小節でちょうど11秒）。四つ打ちのキック、2・4拍のスネア、裏拍のハイハット、8分で跳ねるベース、16分のアルペジオで、コードは Am→F→G→Am→F→E。直前の事務所の場面の終わりに、逆再生のシンバルのような上昇音を置き、不穏な曲はゲーム紹介の頭でフェードアウトさせる。最後の拍にスネアのフィルを入れ、0:33で主音の和音（Am）をキックとクラッシュシンバルと一緒に鳴らして終える。和音とシンバルは約3秒かけて自然に減衰させ、証拠の場面の唸りの下へ消えていく（ぶつ切りに止めると曲が唐突に終わって聞こえるため）
- 音量はCMの曲とそろえる

## 6. 証拠（0:33〜0:37）　試作

黒地に、作中の台詞と調査記録の語句が次々に現れ、無秩序に重なり合いながらフェードアウトしていく。文字は読ませるためではなく、量と気配で見せる。縦書きも混ぜる。新しい語句は、十分に暗くなった語句とだけ重なる位置に置く。「肉付き: 極上」は流れの最後の1語として中央に現れる。大きさとフェードはほかの語句と同じにし、周りの語句が消えていく結果として自然に残って見えるようにする。最後に全体を黒へ落とす。

- 新しい語句は、明るさが0.25以下に落ちた語句とだけ重なってよい。置き場所が見つからなければ小さくして探し直し、それでもなければ出さない
- 位置・大きさ・明るさは乱数（種を固定）で決める。各語句はすぐ現れ、しばらく明るさを保ってから、1.6〜2.8秒で消えきる。出る間隔は0.18秒から0.05秒までだんだん詰める。ほかの語句は0:36.75までに消えきるよう寿命を詰め、最後に出た「肉付き: 極上」だけが残る
- 全面の明滅は入れない
- 冒頭のCMの集合写真と、フックで書いた名前と、ここでつながる
- 音：ゲーム紹介の曲が止まった無音から、低い唸りだけを立ち上げる。語句が出るときの音は付けない
