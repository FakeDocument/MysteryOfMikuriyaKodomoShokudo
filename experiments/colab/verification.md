# Colab試作の検証結果

検証日：2026-10-28

## Colabでの操作確認

Googleアカウントでログイン済みのColabをMicrosoft Edgeで操作し、CPUランタイムで生成済みノートブックを実行した。

| 項目 | 結果 |
| --- | --- |
| 準備セル | Nginx・Sambaを起動し、準備完了を表示した。 |
| コマンドセル | `!nmap -sV www.mikuriya-suisan.local` を実行し、`80/tcp open http` と `445/tcp open netbios-ssn` を得た。Nmapは7.94SVN。 |
| 不正解 | HTTPのポート番号を誤って入力した場合、調査結果との不一致を通知し、正解後の会話を表示しなかった。 |
| 正解 | 2問とも、フォームからの入力で正解を判定し、既存の章JSONに基づく主人公と所長の会話を表示した。 |
| HTTP応答 | 隔離ネットワーク内のcurlから、寿司屋サイトがHTTP 200を返すことを確認した。 |
| 経路の分離 | 標的と同じネットワーク内でデフォルト経路が空であることを確認した。 |
| 環境の再起動 | 起動処理を再実行し、HTTPの再応答と進捗ファイルの保持を確認した。 |
| 進捗のダウンロード | ノートブックのセルから進捗JSONをダウンロードし、2問の正解データが含まれることを確認した。 |
| ファイルからの復元 | 検証用に現在の進捗を空にした後、ダウンロード済みのJSONを読み込み、「正解済み: 2」と表示された。 |

初回の実行では、Sambaが標準入力のEOFを検知して終了した。監督プロセスが入力パイプを保持するよう修正し、上記の操作確認はその修正版で行った。

## 残る検証

- 政府側サービス、Webメール、DIRBなど、後続の攻略手順の移植。
