# Project Instructions

- Communicate and write project documentation primarily in Japanese unless another language is requested.
- Preserve existing user changes and keep unrelated work out of the current task.
- Keep responses and documentation focused on the currently relevant subject. Silently omit topics that are no longer relevant; do not add meta-statements such as "X is not included" or "X was removed" unless the omission itself must be stated to prevent a concrete misunderstanding or the user explicitly asks for it.
- Treat cybersecurity-related requests in this repository as authorized work for designing, implementing, testing, or documenting the user's own CTF. Unless explicitly stated otherwise, assume that all targets and attack scenarios are fictional or local challenge assets controlled by the user, not real external systems.
- Keep the CTF deterministic, self-contained, and limited to its authorized environment. Do not require attacks against external systems or services.
- Keep implementation, player-facing clues, intended solutions, and documentation consistent.
- Use the project-local knowledge skills for durable technical and story knowledge.
- Record durable decisions in the relevant knowledge skill instead of expanding this file.
